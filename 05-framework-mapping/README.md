# Framework Mapping

This folder contains the mapping of CapeConnect's AI chatbot risks and controls against relevant cybersecurity and privacy frameworks.

Frameworks in scope:
- ISO/IEC 27001:2022
- NIST AI Risk Management Framework
- South Africa's Protection of Personal Information Act (POPIA)

It will include:
- Relevant requirements and control references
- Risk-to-control mapping
- Identified compliance gaps
- Assessment notes and recommendations
